## What I would change

There is not a whole lot that I would have changed about my design, but there are still some things. The first one is that I wired my buttons wrong for my Boot and Enable pins for my ESP32, so it was never going to actually turn on until I fixed them. I also had the wrong boot button pin, I did not realize that it had to be a specific pin so I just chose one and went with it. I also had the idea very late into the project to add a test point / extra through hole pin to every pin on my ESP32. This would solve a couple issues. The first is that I did not have enough test points, so in order to test what was going on, I had to try and poke the tiny leads on the ESP itself or on the small surface mount components I had. But this would have also made my PCB design easier to do, and it would have taken less time. Because most parts were surface mount, it was hard to try and connect certain things underneath my PCB to the bottom layer, one because it was my 3.3V line, and also to do undertraces because things were too close together. If I had put an extra hole for every pin, everything could already be wired to the bottom of my board without trying to make a VIA. It would have saved some headache for the PCB design, though it did come out well, I think that that would have helped some. Another thing is my 12V power coming from my barrel jack and shared power on my ribbon cable was connected constantly, because I was using the raw power to move my motor, however it was constantly connected, so if I were to connect to a teamate, my power was going to connect no matter what. Even with my jumpers as a safety measure it was still connected. So I ended up having to cut a trace to remove that posibility of frying my teamate boards or mine not having enough power. I would have wired the ribbon cable power differently, or added another jumper to double ensure that I wanted to connect to shared power, and not just my own seperate power, because even if I was using my own power, it was going to be shared because of my wiring.
